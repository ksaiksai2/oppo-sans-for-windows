# OPPO Sans for Windows

把 **OPPO Sans** 移植成 Windows 系统界面字体（中文 + Win11 壳界面英文 + 经典英文三套一起换），并且**按原字体的度量重新对齐**，所以换完不会有「字变小、按钮文字顶出、行距变宽」这些毛病。

> 本仓库**不包含任何字体文件**。OPPO Sans 请自行从官方渠道下载并同意其条款；微软雅黑等系统字体不随仓库分发。

## 它和网上那些「一键换字体」有什么不同

大多数现成方案只做一件事：把新字体的名字改成 `微软雅黑`，然后覆盖系统文件。能装上，但会出这些症状：

| 症状 | 原因 | 本项目的处理 |
|---|---|---|
| 字变小、字距变松 | 两款字体的字面率不同 | 用「国」字外框把新字体缩放到与原字体**逐单位重合** |
| 按钮文字顶出、标题折行 | 字宽（advance）不同 | 字宽全部取原字体的，实测整串宽度差 **0** |
| 部分符号巨大、重叠 | 几何符号（●○─「」）画法差异大 | 偏差 >15% 的符号一律换回原字形 |
| 网页、输入法出现方框 | 新字体缺字 | 补齐 1057 个缺失字符，最终覆盖 30255 字（比原版多 350） |
| 开始菜单/任务栏英文还是细的 | 壳界面走的是另一套字体 | 同时替换 `Segoe UI Variable` 与经典 `Segoe UI` 五个字重 |

## 前置条件

- Windows 11（22H2 及以上验证过；Win10 未测试）
- 管理员权限
- Python 3.9+（构建用，装完就可以不管它）
- OPPO Sans 4.0 官方字体文件（`OPPOSans40-*.ttf`）

## 用法

**1. 下载字体**

去 OPPO 官网取 OPPO Sans 4.0 的字体包，把这五个文件放进 `input\`：

```
input\OPPOSans40-Light.ttf
input\OPPOSans40-Regular.ttf
input\OPPOSans40-Medium.ttf
input\OPPOSans40-SemiBold.ttf
input\OPPOSans40-Bold.ttf
```

**2. 生成替换字体**

```bat
python src\build.py --weight 600
```

`--weight` 是「正文用哪个字重」，600（半粗）是推荐值，观感最接近手机；400 与原版雅黑同粗细，700 最接近手机的粗体。

输出在 `output\w600\`，共 10 个文件，约 71MB。其中 `msyhsc.ttf` 是一个额外的 **Semibold 面**——
Windows 的标题类控件请求 600 时，如果家族里只有 400/700 就会落到 700，比手机上的 SemiBold 粗一档。

**3. 安装**

右键 `install.cmd` → **以管理员身份运行** → 看到「替换队列已登记」后重启。

**4. 确认**

双击 `check.cmd`，四项都应显示为已替换。

## 恢复

三条路径，按推荐顺序：

1. **系统还原点**（最稳）：安装前建议手动创建一个（`检查点`），出问题在「系统属性 → 系统保护 → 系统还原」回退
2. **`sfc /scannow`**（微软官方兜底）：会把被改的受保护系统文件从组件库换回原版。注意它**不管注册表指向**，跑完还要手动把字体项改回原文件名
3. **右键 `rollback.cmd` → 管理员**（最快）：还原三个雅黑文件 + 撤销全部注册表指向，重启生效

如果字体文件权限坏了导致中文变成宋体（字号小一档、带衬线尖角），右键 `fix-acl.cmd` 修权限后重启。

## 已知限制

- **hinting 丢失**：重建的字体没有原版的大量 hinting 指令，12px 以下的极老 GDI 程序里比原版略软
- **Windows 累积更新会盖回去**：跑一次 `check.cmd` 即可发现，重跑 `install.cmd` 即可
- **斜体没做**：`segoeuii / seguiiz / seguisbi` 仍是原版，界面里出现斜体英文时会跳回原字体（日常几乎遇不到）
- **宋体/等线不动**：指定宋体的文档、指定等线的界面保持原样，这是有意的
- **多用户**：字体是全局的（HKLM），同一台机器的其他账户也会看到替换效果
